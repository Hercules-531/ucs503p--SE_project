01 · Authentication

Send the demo key as a header

curl http://127.0.0.1:8000/api/v1/schemes \
  -H "X-API-Key: {{ demo_key }}"

The key is intentionally public and fixed for this prototype. Phase 3 replaces it with hashed, revocable developer keys.

MethodPathPurpose
