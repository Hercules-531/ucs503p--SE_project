# BharatOS prototype-stage report

The report describes the Phase 1 submission. See the [lab guide](../docs/LAB_GUIDE.md) and
[phased roadmap](../docs/PHASE_ROADMAP.md) for the project's current status.

- [Editable LaTeX](bharatos_report.tex)
- [Compiled report](BharatOS_Software_Engineering_Report.pdf)

The class and bibliography are in this folder. Figures are loaded from
`../docs/diagrams/rendered/`. To compile from this folder with pdfLaTeX and Biber installed:

```text
pdflatex bharatos_report.tex
biber bharatos_report
pdflatex bharatos_report.tex
pdflatex bharatos_report.tex
```
